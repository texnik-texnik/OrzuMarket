# Supabase Role Frontend Skeleton

React + Vite frontend для маркетплейса Orzu с проверкой роли пользователя из таблицы `profiles` после логина.

Логотип маркетплейса находится в `public/orzu-logo.jpg` и используется в шапке, на странице входа и как favicon.

## Роуты и доступ

- `/admin/*` — только `role === 'admin'`
- `/dashboard/*` — только `role === 'seller'`
- `/shop`, `/checkout`, `/profile` — любой авторизованный пользователь
- заблокированный пользователь с `profiles.is_blocked = true` попадает на `/blocked`

После входа пользователь перенаправляется:

- `admin` → `/admin`
- `seller` → `/dashboard`
- `buyer` → `/shop`

## Реализовано

### Покупатель

- Главная страница `/shop` с сеткой товаров
- Фильтрация: поиск, цена от/до, сортировка
- Кнопка «Добавить в корзину»
- Корзина в `localStorage`
- `/checkout` создаёт заказы в таблице `orders`
- `/profile` показывает данные профиля и историю заказов

### Продавец

- `/dashboard/products` — таблица только его товаров
- Кнопка «Добавить товар»
- Модалка: название, цена, описание, загрузка фото, остаток
- Фото загружается в Supabase Storage bucket `product-photos`, а публичный URL сохраняется в `products.photo_url`
- `/dashboard/orders` — заказы, где фигурируют его товары
- Изменение статуса заказа, включая быстрый статус «В пути»

### Админ

- `/admin/users` — список пользователей
- Переключатель buyer/seller
- Переключатель блокировки пользователя
- `/admin/products` — все товары маркетплейса
- Кнопки «Скрыть/Показать» и «Удалить»

## Новые функции и улучшения

### 📊 Статистика и графики (Seller & Admin Dashboards)
- **Панель продавца (`/dashboard`)**:
  - Добавлен интерактивный SVG-график динамики продаж за последние 7 дней (чистая SVG-графика на React с градиентами, подсветкой точек и плавающими всплывающими подсказками при наведении).
  - Карточки показателей (KPI): Общий доход, Количество заказов, Средний чек, Количество товаров.
  - Список последних 4 заказов с ценой и цветными статус-бейджами.
  - Таб **«Топ товаров»** с Stripe-style горизонтальными шкалами распределения популярности продаж и доходов по товарам.
  - Панель быстрого перехода.
- **Панель администратора (`/admin`)**:
  - Карточки показателей (KPI) для всей платформы: Общий доход, Всего заказов, Средний чек, Количество товаров, Количество пользователей.
  - Глобальный SVG-график продаж за последние 7 дней.
  - Список последних заказов и быстрая навигация к управлению пользователями и товарами.

### ⚡ Анимация загрузки (Skeleton Loaders)
- Заменены стандартные текстовые сообщения «Загружаем товары...» на мерцающие серые карточки-заглушки (скелетоны):
  - **Сетка каталога (`/shop`)**: отображается сетка из 6 мерцающих карточек-скелетонов, в точности повторяющих форму товаров.
  - **Таблица товаров админа (`/admin/products`) и продавца (`/dashboard/products`)**: при загрузке отображаются мерцающие строки-заглушки, сохраняя шапку таблицы.
- Внедрен бесконечный CSS-эффект мерцания (shimmer animation) с поддержкой светлой и темной тем.

### 📱 Мобильная навигация (Bottom Navigation Bar)
- Разработана адаптивная нижняя панель навигации (Bottom Navigation Bar) для мобильных устройств.
- На смартфонах и планшетах (при ширине экрана < 820px) громоздкая верхняя шапка скрывается, оставляя только логотип, переключатель языка и темы в одну аккуратную строку.
- Основное меню перемещено вниз и содержит:
  - **Магазин** (иконка пакета покупок)
  - **Избранное** (иконка сердечка с динамическим красным бэйджем количества)
  - **Корзина** (иконка тележки с динамическим красным бейджем количества товаров)
  - **Панель** (иконка графика/портфеля для продавцов и щита для администраторов)
  - **Профиль** (иконка пользователя)
- На странице `/profile` добавлена кнопка «Выйти» для удобного выхода из аккаунта на мобильных устройствах.
- Добавлена поддержка зон безопасного экрана (`safe-area-inset-bottom`) для современных безрамочных смартфонов.

### 🛒 Детальная страница товара, избранное и отзывы (Buyers)
- **Детальная страница товара (`/product/:productId`)**: отображает название, категорию, цену, остаток, подробное описание товара и информационную карточку продавца с его общим рейтингом и ссылкой на магазин. Включает интерактивный селектор количества.
- **Избранное (Wishlist) (`/wishlist`)**: позволяет добавлять товары в персональный список избранного с помощью плавающих сердечек поверх картинок товаров.
- **Отзывы о товаре**: покупатели могут оценивать товары звёздами (1–5) и писать развёрнутые текстовые отзывы. На детальной странице выводится агрегированный рейтинг товара и лента отзывов.

### 🏬 Редактирование и модерация товаров (Sellers & Admins)
- **Модерация товаров**: новые товары от продавцов отправляются в статус «На модерации» и скрыты от покупателей до одобрения админом.
- **Модерационный пульт админа**: в списке товаров админ может быстро одобрять (Approve) или отклонять (Reject) товары с помощью цветных управляющих кнопок.
- **Редактирование товаров продавцами**: продавцы могут изменять название, категорию, цену, описание, остаток и обновлять фотографии товаров. При любом изменении статус модерации автоматически сбрасывается на «На модерации».

### 💳 Симуляция оплаты и отслеживание доставки (Arbitrage)
- **Эмуляция оплаты (Checkout)**: оформление заказа дополнено вводом реквизитов карт Корти Милли или номеров кошельков Alif/DC с реалистичной задержкой авторизации эквайринга, анимациями лоадера и иконками способов оплаты.
- **Отслеживание доставки (Order Tracker)**: в истории заказов покупатель может нажать кнопку «Отследить» для открытия модального окна с динамическим степпером статусов доставки (Оформлен ➔ Оплачен ➔ В обработке ➔ В пути ➔ Доставлен).
- **Арбитраж и споры (`/admin/disputes`)**: покупатели могут открыть спор по любому заказу (выбрав причину: не доставлен, брак, не соответствует). Админ видит очередь споров в панели управления и решает спор в пользу покупателя (отмена/возврат) или продавца (завершение/выплата).

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Если `.env` ещё не заполнен, приложение запустится в demo mode без Supabase. На странице входа доступны тестовые аккаунты:

- `buyer@demo.test`
- `seller@demo.test`
- `admin@demo.test`

Пароль можно ввести любой.

Когда Supabase будет готов:

```bash
cp .env.example .env
# заполнить VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
npm run dev
```

## SQL

Если базовый `supabase_rls.sql` уже применён, дополнительно запустите из корня проекта:

```sql
-- supabase_frontend_features.sql
ALTER TABLE public.products ADD COLUMN IF NOT EXISTS photo_url text;
ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS is_blocked boolean NOT NULL DEFAULT false;
```

В репозитории есть полный файл: `../supabase_frontend_features.sql`.

Для загрузки фото товаров также запустите:

```sql
-- ../supabase_storage.sql
-- создаёт public bucket product-photos и storage policies,
-- чтобы seller мог загружать файлы только в свою папку {seller_id}/...
```

## Главные файлы

- `src/auth/AuthProvider.jsx` — сессия Supabase, загрузка профиля и роли из `profiles`
- `src/routes/ProtectedRoute.jsx` — защищённые роуты по ролям и блокировке
- `src/cart/CartProvider.jsx` — корзина в `localStorage`
- `src/services/marketplace.js` — запросы к Supabase
- `src/App.jsx` — конфигурация маршрутов
- `src/lib/supabase.js` — Supabase client
